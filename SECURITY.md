# Segurança

Encontrou uma falha? Não abra uma issue pública. Use **Security > Report a vulnerability** neste repositório, com os passos para reproduzir e o que ela permite fazer.

## O que está no escopo

- Ver a mão de outro jogador ou a ordem do monte
- Agir no lugar de outra pessoa ou entrar no lugar dela em uma sala
- Derrubar o servidor ou deixar as salas indisponíveis para os outros

## O que o jogo guarda

Não há cadastro nem banco de dados. As salas ficam na memória do servidor, e o navegador guarda só o apelido e a chave para voltar à sala.
